# <img src="../docs/images/icons/gam.png" width="56" align="absmiddle"> Анимации в модах на boopi_mod и G.A.M.: скрипты, диалоги, сцены, камера

[← Все инструкции](README.md) · [Главная страница проекта](../README.md) · Перед этим: [Импорт и свои сцены](ANIMATION_IMPORT.md)

> *Моддинг никогда не был так прост.*

boopi_mod — прежде всего **менеджер модов, в котором вы создаёте своё**: анимации, сценарии, сцены и диалоги — вручную или с помощью
ИИ. Это руководство для модеров: как заставить сыграть анимацию **G.A.M. — менеджера анимаций** из скрипта, из реплики диалога
или из системы «Жизни», как сделать сцену «как в кино» с камерой и как собрать мод, который поставит наш менеджер.

> [!NOTE]
> **⏱ За 1 минуту**
>
> - Анимаций два вида: **жест** (разово, на одном актёре, часть тела поверх того, что он делает) и **сцена** (всё тело, несколько
>   актёров, этапы, камера).
> - В Papyrus: `GAM.Gesture(актёр, "gesture,talk,friendly")` для жеста и `GAM.RunScene("hug,pair", актёры)` для сцены.
> - Анимацию выбирают по **id сцены** или по **запросу по тегам** (`"hug,pair,-intimate"`): так её найдёт любой установленный пак.
> - Из диалога: блок `anim` в `do:` реплики (`id`, `tags` или `context`, `who`, `part`, `when`); из «Жизни»: `OGAIAnim.Context(...)`.
> - Интимные сцены и дети: защита в ядре и в GAM.dll работает всегда, обойти её нельзя; свой мод — это `.gam`-сцены с честными тегами.
> - События сцены (звук, реплика, лицо, надеть/снять, стадия квеста) G.A.M. исполняет сам; ваш скрипт ловит их и начало/конец сцен через
>   `RegisterForExternalEvent("GAM_SceneEvent", ...)`.

Импорт чужих анимаций (Skyrim, OAR) и редактор сцен описаны в [ANIMATION_IMPORT.md](ANIMATION_IMPORT.md).

> [!TIP]
> Без кода всё то же самое делается в программе: **boopi_mod → «Студия скриптов»** — деревья диалогов в формах, анимации в репликах
> с подсказкой «что сыграет», готовые скрипты Papyrus и ИИ-помощник. Подробно — [SCRIPT_STUDIO.md](SCRIPT_STUDIO.md).

Всё описанное проверено в игре (Fallout 4 1.10.163, G.A.M. 0.3.0, BoopiCorp 2.4.4): жест у Стеллы в диалоге, «руки вверх» на NPC и
на герое, кивок только головой, объятие с камерой в обоих режимах.

> [!IMPORTANT]
> Новое в **G.A.M. 0.4.0** — исполнение событий сцены и внешние события для ваших скриптов ([5.2](#52-события-сцены)), лицо и камера
> сцены по дорожкам ([6](#6-камера-сцены)), «Проиграть в игре» и журнал игры прямо в редакторе ([11](#11-как-проверить-в-игре)) —
> собрано и проверено тестами без игры. В игре уже проверено «Проиграть в игре» (запуск, «Стоп», отказ, когда перед героем никого
> нет); остальное **в игре ещё не проверялось**. Если что-то из этого ведёт себя не так, как написано, — это ошибка, а не ваша.

## 1. Два способа анимировать

| | **Разовая анимация (жест)** | **Сцена** |
|---|---|---|
| Что это | Один раз, на одном актёре: помахать, кивнуть, почесать затылок, пожать плечами | Как в кино: один или несколько актёров, всё тело, этапы по очереди |
| Тело | Часть тела поверх того, что актёр делает сам (руки — пока идёт, голова — пока говорит) | Всё тело; люди встают на свои метки |
| Камера | Не трогается | Плавает вокруг людей и сама выбирает ракурсы (`auto`) или ею управляет игрок (`free`) |
| Управление игроком | Остаётся | Отключено, пока герой в сцене (обзор остаётся для ручной камеры) |
| Ждёт ли скрипт | Нет: функция сразу возвращает управление | Да: `RunScene` ждёт конца сцены (или используйте `StartScene` без ожидания) |
| Papyrus | `GAM.Gesture(актёр, "gesture,point,forward")` | `GAM.RunScene("hug,pair", актёры)` |
| Диалог (наши деревья) | `do: { anim: { tags: "...", who: npc, part: head } }` | `do: { anim: { tags: "hug,pair", who: both, when: after } }` |
| Через «Жизнь» (с согласием) | `OGAIAnim.Context("talk_gesture", npc, "npc")` | `OGAIAnim.Context("hug", npc)` |

Правило выбора простое:
- если анимация должна пройти «между делом» — это **жест**;
- если ради неё игрок отпускает мышь и смотрит — это **сцена**.

## 2. Быстрый старт: 3 строки Papyrus

```papyrus
; указать вперёд - разовый жест на верхней части тела, NPC продолжает идти
GAM.Gesture(akSpeaker, "gesture,point,forward")

; кивнуть только головой
GAM.Gesture(akSpeaker, "gesture,talk,friendly", "head")

; обнять героя - сцена: камера плавает, управление отключено, скрипт ждёт конца
Actor[] two = new Actor[2]
two[0] = Game.GetPlayer()
two[1] = akSpeaker
GAM.RunScene("hug,pair", two)
```

Чтобы это компилировалось:
- в папке импорта вашего компилятора Papyrus должен лежать `GAM.psc`, исходник которого ставится вместе с G.A.M.;
- `GAM.pex` и `GAM.dll` нужны в игре.

> [!WARNING]
> Если G.A.M. не установлен, вызовы не компилируются (или, при позднем связывании, ничего не делают) — см. [раздел 10.3](#103-проверка-версии)
> «Проверка версии».

## 3. Где берутся анимации: id сцены и запрос по тегам

Каждая анимация G.A.M. — это файл сцены `Data\GAM\Scenes\<путь>\<имя>.gam`. Её **id** — путь без расширения:
`gesture/talk_friendly_f_s1`.

Во всех функциях, где написано `asWhat`, можно передать:
- **id сцены** — сыграет именно её;
- **запрос по тегам** — `"hug,pair"`, `"gesture,talk,-nervous"`. G.A.M. выберет случайную подходящую сцену:
  - нужны все обычные теги, теги с минусом исключают;
  - число ролей должно совпасть с числом актёров;
  - **интимная — никогда** (см. [раздел 9](#9-безопасность)).

> [!TIP]
> Запрос лучше id: игрок мог поставить другие паки, и сцена с нужными тегами найдётся у любого.

Словарь тегов — `data/gam/tags.yaml`. Самые нужные:

| Что | Теги |
|---|---|
| Жест в разговоре | `gesture,talk` + настроение `friendly`, `confident`, `nervous`, `irritated`, `neutral`, `depressed`, `scared`, `shocked`; длина `short` / `medium` |
| Руки вверх | `gesture,surrender` |
| Покурить и поговорить | `gesture,smoke` |
| Указать направление | `gesture,point` + `forward` / `back` / `left` / `right` |
| Отдать честь | `gesture,salute` (+ `military`, `brotherhood`) |
| Помахать | `wave` — в ванильной игре такого клипа нет: нужна своя сцена или пак с этим тегом |
| Пара | `pair` + действие: `hug`, `kiss`, `handshake`, `dance`, `hold_hands` … |
| Один актёр | `solo` |
| Верх / низ тела | `upper_body` / `lower_body` |

**Жесты из коробки.**
- Пак «Жесты из игры» (`gam_gestures`, ставится менеджером) при установке делает из анимаций вашей же игры 64 жеста разговора
  (8 настроений × мужские/женские × 4 клипа) и ещё 9 отдельных: «руки вверх», «курит и говорит», три вида «отдать честь» и
  «указать» в четыре стороны.
- Файлы игры в пак не копируются: клипы читаются из ваших архивов при сборке.
- Id: `gesture/talk_<настроение>_<m|f>_<s1|s2|m1|m2>`, `gesture/hands_up`, `gesture/smoke_talk`, `gesture/salute`,
  `gesture/salute_military`, `gesture/salute_bos`, `gesture/point_<forward|back|left|right>`.

> [!NOTE]
> Каких сцен нет в игре (например, «почесать затылок»), те G.A.M. не сыграет. Такую анимацию нужно сначала сделать в редакторе
> G.A.M. или импортировать с тегами (`scratch`, `upper_body`, `solo`), и тогда запрос `"scratch"` найдёт её.

**Посмотреть, что установлено:**
- в игре: `GAM.ListScenes("gesture,talk")` — массив id;
- в программе: boopi_mod → G.A.M. → Библиотека (поиск по имени, id и тегам; значок «в игре» у сцен, превью, группы по папкам и
  источникам — [подробнее](ANIMATION_IMPORT.md#45-библиотека-найти-сгруппировать-убрать)).

<p align="center"><img src="../docs/images/gam-library-import.png" alt="Библиотека G.A.M.: список сцен с фильтром по тегу и вкладка импорта паков" width="860"></p>

*Библиотека G.A.M. в программе: сцены с тегами (фильтр по тегу, например `hug,pair,-intimate`) и импорт паков — здесь видно, что именно найдёт ваш запрос.*

## 4. Разовая анимация (жест)

```papyrus
int Function Gesture(Actor akWho, string asWhat, string asPart = "") global
```

- `asWhat` — id или запрос по тегам.
- `asPart` — часть тела. Пустая строка значит «как задано в сцене» (`meta.part` или тег `upper_body`). Варианты:

| `asPart` | Что двигается | Пример |
|---|---|---|
| `upper` | всё от поясницы вверх | указать, развести руками, жест в разговоре |
| `head` | шея и голова | кивок, покачать головой, оглянуться |
| `arms` | обе руки (плечи и ниже) | хлопнуть, потереть ладони |
| `left_arm` / `right_arm` | одна рука | почесать затылок правой, поправить волосы |
| `lower` | ноги и таз | переступить, притопнуть |
| `full` | всё тело | — (для всего тела лучше сцена) |

Как ведёт себя жест:
- Играет **один раз** и плавно возвращает актёра к его собственной анимации (вход 0,3 с, выход 0,45 с).
- Остальное тело остаётся своим: можно махать на ходу.
- Камера и управление не трогаются. Функция возвращает handle (0 — подходящей сцены нет) и сразу отдаёт управление скрипту.
- Сначала ищется клип под пол актёра: с тегом `male` или `female`. Только если такого нет, берётся любой.

Примеры:

```papyrus
GAM.Gesture(akSpeaker, "gesture,talk,confident")                 ; уверенный жест верхом тела
GAM.Gesture(akSpeaker, "gesture,talk,friendly,short", "head")    ; только кивок
GAM.Gesture(Game.GetPlayer(), "gesture,surrender")               ; герой поднимает руки
GAM.Gesture(akGuard, "gesture/talk_irritated_m_s1", "right_arm") ; конкретная сцена, только правая рука
```

Более низкий уровень, если нужно своё поведение:

```papyrus
int h = GAM.PlayPart("gesture/hands_up", actors, "upper")   ; играет, пока не остановят (если в сцене есть петля)
GAM.Stop(h)                                                 ; доиграть и выйти; GAM.Stop(h, true) - сразу
int o = GAM.OverlayPart(akActor, "drunk_sway", "upper", 0.6) ; слой с весом, пока не остановят
GAM.SetWeight(o, 0.3)
```

## 5. Сцена

```papyrus
bool Function RunScene(string asWhat, Actor[] akCast, ObjectReference akFurniture = None, \
                       float afSecondsPerStage = 0.0, float afMaxSeconds = 0.0, string asCamera = "") global
```

- `akCast` — актёры в порядке ролей сцены. Для пары обычно `[0]` — герой, `[1]` — NPC.
- `akFurniture` — мебель-якорь (кровать, диван): сцена встанет на неё. Без мебели сцена ставится на месте первого актёра, остальные —
  относительно него.
- `afSecondsPerStage`:
  - `0` — каждый этап играет столько проходов, сколько записано в сцене;
  - `> 0` — каждый этап крутится целыми проходами, пока не пройдёт столько секунд.
- `afMaxSeconds` — предел всей сцены. Сцена **без этапов** зациклена и без предела шла бы вечно, поэтому по умолчанию 20 с.
- `asCamera` — `"auto"`, `"free"`, `"off"`; пустая строка значит «как в GAM.ini» (по умолчанию `auto`).

Что происходит при вызове:
1. Подбирается сцена (`PickScene`).
2. Актёры плавно встают на метки: тела «доезжают», а не прыгают. Если NPC пытается уйти по своему AI, G.A.M. возвращает его на метку.
3. Включаются этапы ([5.1](#51-этапы-развитие-сцены)) и камера ([раздел 6](#6-камера-сцены)).
4. Пока в сцене герой, отключены ходьба, бой, меню и смена вида; обзор работает — им крутят ручную камеру.
5. В конце сцена выходит из петли, актёры плавно возвращаются к своим анимациям, управление возвращается.

Если подходящей сцены нет, `RunScene` возвращает `false`.

Без ожидания (например, чтобы перелистывать этапы самому):

```papyrus
int h = GAM.StartScene("dance,pair", two, None, 0.0, "auto")   ; 0 = не нашлось
if h > 0
    Utility.Wait(5.0)
    GAM.NextStage(h)          ; сразу следующий этап (false: это был последний - выход)
    GAM.WaitScene(h, 60.0)    ; дождаться конца, не дольше минуты; управление героя отключено на это время
endif
```

### 5.1 Этапы (развитие сцены)

Сцена с этапами идёт **по порядку**: каждый этап крутится свои проходы, потом следующий, после последнего — выход. Так делаются
«развивающиеся» сцены: знакомство → объятие → танец.

Этапы задаются в файле сцены одним из двух способов:
- `meta.stages: [{ "name": "stage1", "start": 0, "end": 4, "loops": 2 }, ...]` — точные границы и число проходов;
- маркеры `markers: { "stage1": 0.0, "stage2": 4.0, "stage3": 9.5 }` — этап идёт от своего маркера до следующего (последний — до
  конца), по одному проходу.

В редакторе G.A.M. этапы размечаются без JSON — секция «Часть тела и этапы» ([10.4](#104-правка-сцены-в-редакторе-отмена-ключи-зеркало-время)).

Функции:
- `GAM.StageCount(h)` — сколько этапов (0 — сцена без этапов, просто петля);
- `GAM.GetStage(h)` — текущий этап, 1…N;
- `GAM.NextStage(h)` — перейти к следующему этапу сейчас;
- `GAM.Staged(h, сек)` — включить пошаговый режим вручную (`StartScene` делает это сам).

### 5.2 События сцены

Сцена может нести события (`events` в файле; в редакторе — раздел «События»). В свой момент G.A.M. **исполняет их сам** (с 0.4.0) на
актёре роли события (`target`; пусто — первая роль сцены), где бы сцену ни запустили — из скрипта, диалога, «Жизни» или редактора:

| Тип | Значение | Что происходит в игре |
|---|---|---|
| `sound` | форма звука (SNDR): `Плагин\|0xID`, например `Fallout4.esm\|0x0001A4E1` | звук у актёра (`Sound.Play`) |
| `say` | топик (DIAL): `Плагин\|0xID` | актёр говорит реплику (`Say`) |
| `expression` | выражение лица: `happy`, `angry`, `sad`, `afraid`, `surprised`, `in_pain` … (35 выражений Fallout 4, список — в редакторе); пусто — своё лицо | лицо до следующего выражения или до конца сцены (`ChangeAnimFaceArchetype`) |
| `equip` | предмет: `Плагин\|0xID` | актёр надевает его (тихо; нет в инвентаре — появится) |
| `unequip` | предмет: `Плагин\|0xID` | актёр снимает его |
| `stage` | квест и стадия: `Плагин\|0xID\|стадия` | `SetStage` квеста |
| своё слово | что угодно | само ничего — это событие для вашего скрипта |

`0xID` — номер формы в её плагине, как его показывают xEdit и Creation Kit, без индекса загрузки (плагины ESL тоже подходят).
Лицо, которое поставила сцена, после её конца возвращается.

Ваш скрипт слышит каждое событие (и свои слова тоже) и начало и конец каждой сцены — через **внешние события F4SE** (в Fallout 4 это
замена ModEvent из Skyrim):

```papyrus
Scriptname MyGamListener extends Quest

Event OnQuestInit()
    Listen()
    RegisterForRemoteEvent(Game.GetPlayer(), "OnPlayerLoadGame")
EndEvent

Event Actor.OnPlayerLoadGame(Actor akSender)
    Listen()                                   ; после загрузки сохранения - ещё раз, так надёжнее
EndEvent

Function Listen()
    RegisterForExternalEvent("GAM_SceneEvent", "OnGamEvent")
    RegisterForExternalEvent("GAM_SceneStart", "OnGamStart")
    RegisterForExternalEvent("GAM_SceneEnd", "OnGamEnd")
EndFunction

Function OnGamEvent(int aiHandle, string asScene, string asType, string asValue, Actor akActor, string asRole)
    if asType == "door_knock"                  ; своё событие: в редакторе тип «своё (для скриптов)»
        Debug.Notification(asScene + ": стук в дверь")
    endif
EndFunction

Function OnGamStart(int aiHandle, string asScene, Actor[] akActors)
EndFunction

Function OnGamEnd(int aiHandle, string asScene, Actor[] akActors)
EndFunction
```

- Сигнатуры функций должны быть ровно такими (имена — любые, их вы передаёте в `RegisterForExternalEvent`).
- `GAM_SceneStart` / `GAM_SceneEnd` приходят для сцен, жестов и слоёв (для походок — нет).
- Очередь `GAM.NextEvent(h)` осталась — для скрипта, который хочет читать события в своём цикле:
  `"type|target|value"`, `"end||"` когда сцена кончилась, `""` — пока ничего.
- В `GAM.log` каждое исполненное событие — строка `event <тип> '<значение>' on <актёр>`; не нашлась форма или у роли нет актёра —
  предупреждение `event say: no topic '…'`.

## 6. Камера сцены

Камера включается **только для сцен** (`RunScene` / `StartScene`, наши диалоги и «Жизнь», когда в сцене есть герой). Жесты её не
трогают.

| Режим | Как ведёт себя |
|---|---|
| `track` (камера сцены) | Сцена с **дорожкой камеры** (редактор → «Камера сцены») снимается ею: место, поворот и поле зрения по ключам, относительно начала сцены. Такая сцена берёт этот режим сама. |
| `auto` (по умолчанию) | Сама: 6 планов по кругу — спереди сбоку, сбоку ближе, через плечо сзади, сверху с другой стороны, низко и близко, общий спереди. Внутри плана медленно облетает людей и чуть наезжает; между планами плавно переезжает (2,5 с). Смотрит на уровень груди, все люди в кадре. |
| `free` | Вручную: мышь или стрелки — вокруг людей, PageUp / PageDown или колесо — ближе / дальше. |
| `off` | Обычная камера игры. |

Как управлять камерой:
- **F7** во время сцены переключает режимы по кругу: `auto → free → off → auto`; у сцены с дорожкой камеры — `track → auto → free →
  off → track` (из `track` облёт начинается с того места, где была камера сцены).
- Если герой был от первого лица, на время сцены камера переходит в третье лицо, а после сцены возвращается. Для `track` так же, даже
  когда героя в сцене нет.
- Выход всегда безопасный: сцена кончилась (или её остановили) — камера, вид от первого лица и поле зрения игры возвращаются; F7 до
  `off` — сразу камера игры.
- Режим из скрипта: `GAM.Camera(h, "free")`, узнать текущий — `GAM.CameraMode()` (пустая строка, если камера ни за чем не следит).

Настройки — `Data\F4SE\Plugins\GAM.ini`, раздел `[Camera]`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `sMode` | `auto` | режим по умолчанию |
| `iSwitchKey` | `118` | клавиша переключения (код Windows: F7 = 118, F8 = 119) |
| `fShotSeconds` | `7` | сколько длится план |
| `fGlideSeconds` | `2.5` | переезд между планами |
| `fOrbitDegrees` | `5` | градусов в секунду облёт внутри плана |
| `fDistance` | `1.0` | множитель расстояния (в тесных комнатах 0,7) |
| `fHeight` | `35` | высота точки взгляда над центром людей (35 — грудь) |
| `bMessages` | `1` | надпись о смене режима (видна, если HUD не скрыт) |
| `bDebug` | `0` | 1 — планы камеры пишутся в `Documents\My Games\Fallout4\F4SE\GAM.log` |
| `bSceneCamera` | `1` | сцена с дорожкой камеры снимается ею (`track`), если скрипт не назвал режим; 0 — никогда |

Раздел `[Editor]`: `bLink=1` — игра принимает сцены из редактора («Проиграть в игре», [11](#11-как-проверить-в-игре)); 0 — не спрашивает
программу вовсе.

> [!WARNING]
> Ограничения камеры:
> - Камера не знает стен: в тесном месте план может оказаться за колонной или стойкой микрофона. Тогда помогают F7 → ручной режим
>   или меньший `fDistance`.
> - Во время сцены HUD скрыт, поэтому надпись о режиме может не появиться.
> - Поле зрения из дорожки камеры (ключи «Поле зрения») ставится в поле зрения игры на время сцены — это экспериментально; без этих
>   ключей поле зрения остаётся игровым.

## 7. Анимация из диалога

### 7.1 Наши деревья диалогов (`data/talk/*.yaml`)

В блок последствий `do:` любой реплики (вариант героя или ответ NPC)
можно добавить `anim`:

```yaml
do: { anim: { tags: "gesture,talk,friendly", who: npc, part: head, when: line } }
```

| Поле | Значения | Смысл |
|---|---|---|
| `id` | id сцены из библиотеки G.A.M. (`my/wave`) | именно эта сцена (для жеста — на одну роль, для `both` — на две); сцену из библиотеки «В игру» студии поставит в игру сама |
| `tags` | запрос по тегам | анимация напрямую из G.A.M. (жест — одному, сцена — для `both`) |
| `context` | id контекста (`data/gam/contexts`) | анимацию подбирает ядро; интимная — только с согласием ([раздел 8](#8-через-систему-жизни-контексты)) |
| `who` | `npc` (по умолчанию) / `player` / `both` | на собеседнике, на герое или сцена на двоих |
| `part` | `head`, `upper`, `arms`, `left_arm`, `right_arm`, `lower`, `full` | часть тела (по умолчанию — как в сцене) |
| `when` | `line` (по умолчанию) / `after` | сейчас, пока звучит реплика, или когда разговор закончится |

Нужно **ровно одно** из трёх: `id`, `tags` или `context` (нет ни одного или названо несколько — проверка студии и `check_talk.py`
скажут об ошибке). По `id` и по тегам интимная сцена не берётся никогда (только контекстом, с согласием). Запрос по тегам (в нём
есть запятая), написанный в `id` или `context`, читается как `tags`. Если `who: both`, это всегда
**сцена** с камерой. Её лучше ставить с `when: after`, чтобы она не спорила с камерой диалога.

Та же форма «сыграть сцену» — в триггерах Студии (`scene:`) и в строках мира миссий
([MISSION_WORLD.md](../docs/story/MISSION_WORLD.md)): ровно одно из `id` / `tags` / `context`. Вместо `who: npc | player | both` и
`when` там `actors: [hero, EDID…]` (для `id` и `tags`) или `npc` + `who: both | npc` + `part` (для `context`, без `actors`); строки
мира принимают и `context`. Подробно — [SCRIPT_STUDIO.md](SCRIPT_STUDIO.md#123-действия-что-произойдёт).

**Пример: маленький диалог с жестом головы и рук.**

```yaml
trees:
  my_barman:
    who: [MyModBarman]
    title: { ru: "Бармен", en: "Barman" }
    flags: [met]
    greet:
      - { when: { not: met }, go: first, do: { set: met }, ru: ["Новенький? Садись."], en: ["New here? Take a seat."] }
      - { go: first, ru: ["Опять ты. Что налить?"], en: ["You again. What'll it be?"] }
    nodes:
      first:
        - slot: question
          label: { ru: "Что у вас тут?", en: "What's this place?" }
          reply:
            # ответ с кивком: двигается только голова, руки продолжают протирать стакан
            - { do: { anim: { tags: "gesture,talk,friendly,short", who: npc, part: head } },
                ru: ["Бар. Лучший в квартале. Единственный в квартале."], en: ["A bar. Best on the block. Only one on the block."], go: first }
        - slot: positive
          label: { ru: "Выглядишь уставшим.", en: "You look tired." }
          reply:
            # жест верхом тела: развёл руками, ноги стоят как стояли
            - { do: { anim: { tags: "gesture,talk,depressed", who: npc } },
                ru: ["Третья смена подряд. А ты как думал{p:а|}?"], en: ["Third shift in a row. What did you think?"], go: first }
        - slot: negative
          label: { ru: "Руки вверх! Шучу.", en: "Hands up! Kidding." }
          reply:
            - { do: { anim: { tags: "gesture,surrender", who: npc } },
                ru: ["Очень смешно. Я чуть бутылку не уронил."], en: ["Very funny. Nearly dropped a bottle."], go: first }
        - slot: neutral
          label: { ru: "Мне пора.", en: "I should go." }
          reply:
            # на прощание показать на дверь - уже после разговора, на ходу
            - { do: { anim: { tags: "gesture,point,forward", who: npc, when: after } }, ru: ["Выход там. Заходи ещё."], en: ["Door's that way. Come again."], go: end }
```

Проверка дерева (ошибки в `anim` — неизвестное поле, `who`, `part`, `when` — проверка находит):

```bash
uv run --project core python scripts/check_talk.py data/talk/my_barman.yaml
```

Прокликать такой разговор можно и без игры: **«▶ Сыграть диалог»** в Студии ([SCRIPT_STUDIO.md](SCRIPT_STUDIO.md#31-играть-проверить-разговор-без-игры)).
Анимацию проигрыватель не играет, а показывает, сколько сцен подходит под теги реплики.

Дальше дерево собирается в плагин вместе с остальными:
- в каждую реплику с `anim` попадают свойства `AnimContext` / `AnimTags` / `AnimPart` / `AnimWho` / `AnimWhen` скрипта
  `OGAITreeInfoScript` (id сцены идёт в `AnimTags`: `GAM.PickScene` сначала ищет сцену с таким id);
- в игре реплика зовёт `OGAILifeScript.TreeAnim`.

Живой пример — `data/talk/black_acorn_singer.yaml`, Стелла: комплимент — дружелюбный жест; «Спой что-нибудь» — уверенный;
«Я просто слушаю» — кивок.

### 7.2 Свой диалог в Creation Kit

В фрагменте реплики (TopicInfo) — обычный Papyrus:

```papyrus
Scriptname MyMod_TIF_Barman_Nod extends TopicInfo Hidden

Event OnBegin(ObjectReference akSpeakerRef, bool abHasBeenSaid)
    GAM.Gesture(akSpeakerRef as Actor, "gesture,talk,friendly,short", "head")   ; кивок, пока говорит
EndEvent
```

- Начало реплики — `OnBegin`, конец — `OnEnd`.
- Сцену на двоих лучше запускать в `OnEnd` последней реплики: камера диалога к этому времени уже отпущена.

```papyrus
Event OnEnd(ObjectReference akSpeakerRef, bool abHasBeenSaid)
    Actor[] two = new Actor[2]
    two[0] = Game.GetPlayer()
    two[1] = akSpeakerRef as Actor
    GAM.RunScene("hug,pair", two)
EndEvent
```

## 8. Через систему «Жизни»: контексты

**Контекст** — это смысловое место, где нужна анимация: «помахать», «жест в разговоре», «объятие», «танец вдвоём», «близость».
Контекст сам не называет сцену. В нём записаны запросы по тегам по порядку предпочтения, вид (`overlay` — жест, `scene` — сцена,
`gait` — походка), число актёров, часть тела и подходящая мебель. Файлы — `data/gam/contexts/*.yaml`. Свои контексты кладутся в
`%APPDATA%\BoopiMod\gam\contexts\*.yaml`.

**Свои контексты в программе.** Их не обязательно писать руками: **G.A.M. → Библиотека → «Контексты» → «+ Свой контекст»**. В форме —
id (латиница, цифры, `_`), вид («сцена», «слой» — это `overlay`, «походка»), название по-русски и по-английски, запросы по тегам (по
одному в строке, первый подходящий выигрывает), для сцены число актёров и «Где можно играть» (мебель), часть тела. Такие контексты
программа хранит в `%APPDATA%\BoopiMod\gam\contexts\app.yaml` и показывает в списке «Мои контексты» с кнопками «Изменить» и «Удалить».
Файлы, которые вы написали сами, она не трогает и показывает только для чтения («ваш файл»); контексты установленных модов
подписаны «из мода …». Id нельзя взять тот, что уже есть у программы, у мода или в вашем файле. Отметку 18+ редактор не ставит:
свой контекст интимную сцену не возьмёт. Рядом с каждым контекстом видно, сколько установленных сцен ему подходит («подходит: N»).

Свои контексты, которые называют реплики и триггеры вашего мода (`anim.context`, `scene.context`), и свои группы рас, упомянутые в
ролях упакованных сцен (`@группа`), «Сохранить мод» кладёт в `.ogmod` сам. У того, кто мод поставит, они читаются рядом с его
собственными и уходят вместе с модом; чужой контекст или группа с тем же id не перекрываются — установка откажет
([SCRIPT_STUDIO.md](SCRIPT_STUDIO.md#9-свой-мод-сохранить-и-поделиться)).

Вызов из Papyrus (нужны BoopiCorp.esp и запущенный boopi_mod):

```papyrus
OGAIAnim.Context("talk_gesture", akNpc, "npc") ; жест на NPC
OGAIAnim.Context("hug", akNpc)                 ; сцена героя и NPC: камера, этапы, ожидание конца
OGAIAnim.Tags("gesture,talk", akNpc, "npc")    ; то же по тегам, без ядра (GAM.Gesture / GAM.RunScene)
```

Чем вызов через ядро отличается от прямого:
- ядро выбирает сцену под этих людей и это место: пол, мебель рядом, «тот же человек — та же манера»;
- вид вызова берётся из контекста: `overlay` — жест, `scene` — сцена;
- **интимный контекст** (`intimacy`) играет только после согласия по правилам ядра, и только со взрослыми людьми.

Действия «Жизни» (`act: hug`, `act: kiss` в деревьях) уже связаны с контекстами через `verbs:` в `life.yaml`: успех действия сам
играет свой контекст.

**Походки и курение.** Болезнь, ломка, похмелье, усталость и износ просят **походку** по контексту из `body.yaml` (`sick_cough`,
`withdrawal_crisis`, `worn` …), живой город — **курение** (`amb_smoke`); для скриптов есть ещё `smoke_light`, `smoke_out`,
`smoke_wall` (у стены) и `smoke_sit` (сидя). Отвечает то, что стоит в игре и несёт нужные теги. Программе не нужен ни один
чужой мод анимаций: если ничего не подошло, человек ходит своей походкой игры, а жест просто не играет — ничего не ломается.
Свою походку можно сделать в редакторе: набор сцен с `meta.gait` (стойка, шаг и бег по направлениям, мужской и женский) в
папке `…/gait/<набор>/` — подробности в `docs/GAM.md`, «Походка по условию».

## 9. Безопасность

> [!IMPORTANT]
> Эти правила не отключаются нигде.

- **Близость** (`intimate`) — только через ядро и его согласие: стадия отношений, доверие, трезвость, не на людях, никогда за плату.
  Только взрослые люди, никогда пленник, никогда «forced».
- `GAM.PickScene`, `GAM.RunScene`, `GAM.Gesture` и `OGAIAnim.Tags` **никогда** не выбирают интимную сцену по тегам.
- **Дети.** GAM.dll не запустит сцену с тегами близости или романтики (`intimate`, `romance`, `kiss`, `sex`, `nsfw`, `flirt`), если
  среди актёров ребёнок, — кто бы её ни вызвал. Ядро не сохранит и не поставит сцену, где ребёнок в интимной роли.
- **Внешние паки.** Сцена из пака другого мода на двоих и больше, где не названо простое безопасное действие (объятие, поцелуй,
  рукопожатие, танец), считается интимной и идёт только через согласие.
- **Люди и животные** — никогда.

Если ваш мод зовёт сцену и она не играет, загляните в `GAM.log`. Строка `is a scene of closeness: never with a child` означает, что
сработала эта защита. Обойти её нельзя, и так задумано.

## 10. Мод для нашего менеджера

### 10.1 Что класть в архив

```
MyMod.zip
└─ Data/
   ├─ MyMod.esp                         ; ваш плагин (NPC, диалоги CK, квесты)
   ├─ Scripts/MyMod_*.pex               ; ваши скрипты (GAM.pex НЕ кладите - он из пака G.A.M.)
   └─ GAM/Scenes/mymod/
      ├─ barman_wipe_glass.gam          ; свои сцены: id = "mymod/barman_wipe_glass"
      └─ barman_toast.gam
```

- Сцены кладите в **свою папку** (`GAM/Scenes/<ваш_мод>/`), чтобы id не пересеклись с чужими.
- Ставьте своим сценам **честные теги**. По ним их найдут контексты и запросы других модов. Пара — `pair`, один актёр — `solo`, верх
  тела — `upper_body`, близость — `intimate` (без этого тега ядро не пустит сцену в интимный контекст, а с ним — не пустит никуда
  больше).
- В описании мода укажите зависимость: G.A.M. 0.3.0+ (и «Жесты из игры», если зовёте `gesture,talk…`).
- Менеджер ставит такой архив как обычный мод (жёсткие ссылки и журнал, откат одной кнопкой). G.A.M. сам находит новые сцены
  (`GAM.Reload()` или при следующей загрузке).

> [!TIP]
> Удобнее всего собрать мод в «Студии скриптов»: «Сохранить мод» → отметьте свои сцены G.A.M. — они уедут в `.ogmod` вместе с
> диалогами, а с ними и ваши контексты с группами рас ([раздел 8](#8-через-систему-жизни-контексты),
> [SCRIPT_STUDIO.md](SCRIPT_STUDIO.md)).

> [!WARNING]
> **Чужие анимации.** Сцена, собранная из чужих анимаций (импортированный пак, Skyrim, конвертированные походки OAR, клипы плагина),
> несёт чужое движение: делиться ею можно только с разрешения его автора. «Сохранить мод» за вас этого не решает, но предупреждает:
> такие сцены названы в предупреждениях и помечены «чужое» в списке, а флажок «Только мои сцены» оставляет в моде лишь то, что
> сделали вы сами. Копия («Сохранить как…», «Копия») чужой сцены остаётся «чужой».

### 10.2 Минимальный файл сцены

```json
{
  "gam": 1, "id": "mymod/barman_toast", "name": "Тост", "mode": "absolute",
  "duration": 2.4, "loop": false, "blend": { "in": 0.3, "out": 0.45 },
  "tags": ["toast", "drink", "solo", "upper_body"],
  "roles": [ { "id": "a", "label": "A", "skeleton": "human", "sex": "any" } ],
  "tracks": [
    { "kind": "bone", "target": "a", "name": "RArm_UpperArm",
      "rot": [ { "t": 0, "q": [1, 0, 0, 0] }, { "t": 1.2, "q": [0.92, 0.38, 0, 0], "i": "auto" }, { "t": 2.4, "q": [1, 0, 0, 0] } ] }
  ],
  "props": [], "events": [], "markers": {},
  "meta": { "part": "upper" }
}
```

Основные поля:
- `roles` — актёры по порядку: `id`, `sex` (`male` / `female` / `any`), `skeleton` (`human`).
- `tracks` — ключи костей; кватернион `[w, x, y, z]` в локальных осях кости, как в клипах игры.
  - `kind: root` — место и курс актёра относительно начала сцены (для пар).
- `markers` — `loop_start` / `loop_end` (петля: вход — петля пока не остановят — выход) и `stage1…N` (этапы, [5.1](#51-этапы-развитие-сцены)).
- `meta.part` — часть тела по умолчанию; `meta.stages` — этапы с числом проходов.
- `props` — объекты: мебель-якорь (`anchor: true`), предмет на месте или предмет в руке (`kind: held`, `role` + `bone`);
  `form` — `Плагин.esm|0x0004D1F9`. В окне редактора у них настоящие модели из вашей игры (если модель есть), а не коробки.

Сцены удобнее делать в редакторе G.A.M. (boopi_mod → G.A.M.): там
скелет, таймлайн, ключи, IK-ручки, проверка и установка в игру одной кнопкой. Как с ним работать — [ANIMATION_IMPORT.md](ANIMATION_IMPORT.md).

<p align="center"><img src="../docs/images/gam-editor-ik-ai.png" alt="Редактор G.A.M.: IK-ручки на теле, панель света, таймлайн и журнал ИИ-аниматора" width="860"></p>

*Редактор G.A.M.: ключи ставятся кольцами и IK-ручками прямо на теле, а ИИ-аниматор по описанию словами расставляет участников и делает черновик движения.*

> [!NOTE]
> Служебные кости ванильных клипов (`Camera`, `CamTarget`, `Weapon*`, `AnimObject*`, IK-цели, `PipboyBone`) G.A.M. не двигает
> никогда: камера сцены своя, оружие и предметы в руках идут за кистью.

### 10.3 Проверка версии

```papyrus
if GAM.GetVersion() >= 300        ; 0.3.0: этапы, камера, PickScene, RunScene, Gesture
    GAM.Gesture(akSpeaker, "gesture,salute")
endif
if GAM.GetVersion() >= 400        ; 0.4.0: события исполняются, GAM_SceneEvent, лицо и камера сцены, SetFace
    GAM.SetFace(akSpeaker, "happy")
endif
```

> [!TIP]
> Если ваш мод должен работать и без G.A.M., вызывайте его функции из отдельного скрипта: тогда отсутствие GAM.pex сломает только этот
> скрипт, а не весь мод. Скрипты Papyrus связываются поздно.

### 10.4 Правка сцены в редакторе: отмена, ключи, зеркало, время

Всё ниже — в G.A.M. (boopi_mod → G.A.M.), справа в инспекторе секции **«Часть тела и этапы»** и **«Правка»**. Полный список клавиш —
кнопка **«?»** в панели редактора (или клавиша `?`); клавиши работают и в русской раскладке.

**Отмена.** Любая правка сцены отменяется: ключи, повороты, перетаскивание IK-шарика (одно перетаскивание — один шаг), роли,
объекты, события, маркеры, этапы, настройки сцены, оптимизация и результат ИИ-аниматора. `Ctrl+Z` — отменить, `Ctrl+Y` или
`Ctrl+Shift+Z` — вернуть; кнопки «Отменить» / «Вернуть» в панели подсказывают, что именно. Набор текста в одном поле (имя сцены)
или движение одного слайдера — один шаг. История хранит до 100 шагов, пока программа открыта. `Ctrl+S` — сохранить; закрыть окно с
несохранённой сценой программа не даст молча, а сама сцена и так переживает перезапуск черновиком.

**История версий.** Отмена живёт, пока программа открыта. А то, что уже сохранено, не пропадает: перед каждым сохранением или удалением
предыдущая версия сцены откладывается (последние 12), и кнопка **«История»** в панели вернёт любую из них
([ANIMATION_IMPORT.md](ANIMATION_IMPORT.md#44-сохранить-и-в-игру)).

**Ключи на таймлайне.**

| Действие | Как |
|---|---|
| Выбрать ключ | щелчок |
| Добавить / убрать из выбранных | `Shift` или `Ctrl` + щелчок |
| Выбрать рамкой | протянуть мышью по пустому месту дорожек (с `Shift` — добавить) |
| Сдвинуть выбранные | тянуть любой выбранный ключ — едут все, по кадрам; `Alt+←/→` — на кадр (`Alt+Shift` — на 10) |
| Удалить выбранные | `Delete` |
| Все ключи / ключи в этот момент | `Ctrl+A` / кнопка «Ключи в этот момент» |
| Курсор | линейка сверху; `←/→` — кадр, `Shift+←/→` — 10 кадров, `Home`/`End`, `[`/`]` — предыдущий / следующий ключ |

Тип перехода и мягкость в секции «Ключ» меняются сразу у всех выбранных ключей. Там же **вес дорожки** — насколько эта дорожка
ложится поверх (слой).

**Поза.** `Ctrl+C` копирует позу роли в текущий момент (все анимированные кости), `Ctrl+V` вставляет её ключами в текущий
момент — на ту же роль или на другую (выбор «→ роль» в «Правке»): так поза переносится с актёра на актёра или из одной сцены в
другую.

**Зеркало (лево ↔ право).**
- **Зеркало позы** (`M`) — поза в текущий момент отражается: махал правой рукой — машет левой.
- **Зеркально** (`Shift+M`) — выбранные ключи переходят на другую сторону; если выбраны обе стороны, они меняются местами.
  Выберите все ключи (`Ctrl+A`) — отразится весь клип, вместе с путём персонажа по сцене.
- **Копия на другую сторону** — выбранные ключи остаются, а их отражение ложится на другую сторону: симметричное движение
  (обе руки вверх) из одной руки.

Пары костей берутся из имён скелета (`LArm_*` ↔ `RArm_*`, `LLeg_*` ↔ `RLeg_*`); отражение учитывает позу покоя скелета, поэтому
отражённая поза — точное зеркало, а не «примерно похожая». Лицо и служебные кости (оружие, камера) не отражаются.

**Время.** Поле «Множитель времени»: `2` — вдвое медленнее, `0.5` — вдвое быстрее.
- «Растянуть выбранные» — только выбранные ключи, от первого из них; с галочкой «Сдвинуть то, что после» всё, что идёт после них
  (ключи, события, маркеры, этапы), едет следом.
- «Растянуть сцену» — вся сцена целиком: ключи, события, маркеры, этапы, объекты и длина.

**Шов петли.** Зацикленная сцена (галочка «Петля» или маркеры петли) дёргается, если последний кадр петли не совпадает с первым —
частая беда импортированных клипов. «Сшить петлю» делает конец петли равным её началу, а ключи в «окне сглаживания» перед концом
(по умолчанию 0,3 с) плавно подводит к шву.

**Этапы и часть тела.** «Часть тела по умолчанию» — `meta.part`: какие кости сцена ведёт, если вызов не сказал иначе (жест только
руками поверх ходьбы и т. п.). «Этапы» — `meta.stages` ([5.1](#51-этапы-развитие-сцены)): имя, начало, конец и число проходов;
«+ Этап до курсора» и «Разрезать в курсоре» размечают сцену по таймлайну, этапы видны полосами на линейке.

**Во весь экран.** Кнопка **«⛶ Во весь экран»** в панели редактора (или `F11`) отдаёт всё окно виду и таймлайну: боковое меню, шапка и
правая колонка прячутся, а свойства и библиотеку открывает кнопка **«☰ Панель»** — они выезжают поверх картинки. Кнопка
**«⤢ Экран»** занимает ещё и весь монитор (без рамки окна); программа помнит, каким режимом вы пользовались в последний раз. Выйти
— `F11` или «Выйти»; `Esc` сначала закрывает панель, потом отпускает выбранные ключи, потом выходит. Сцена, выбор, курсор и
история отмены при этом не теряются.

## 11. Как проверить в игре

**Быстрее всего — прямо из редактора G.A.M.** (G.A.M. 0.4.0):

1. Запустите игру и загрузите сохранение; boopi_mod открыт.
2. В G.A.M. откройте или сделайте сцену и нажмите **«▶ В игре»** (или вкладка «В игре» справа). Сохранять сцену не нужно: в игру уходит
   то, что сейчас в редакторе.
3. Выберите, кто играет каждую роль — **Герой**, **NPC под прицелом** (выбранный в консоли щелчком или стоящий прямо перед героем) или
   **Ближайший NPC**, — камеру и предел в секундах, и нажмите **«▶ Проиграть в игре»**.
4. Строка состояния: «Отправлено» → «Игра взяла сцену» → «Играет» → «Сыграла». «Не сыграла» — с причиной (нет сохранения, никого
   перед героем, раса не подходит роли…). **«■ Стоп»** заканчивает сцену; управление героя возвращается.
5. Ниже — **«Журнал игры (GAM.log)»**: строки про эту сцену (или все) с подсказкой, что делать.

Игра принимает сцены, только пока в `GAM.ini` `[Editor] bLink=1` (по умолчанию). Надпись «Игра на связи» значит, что GAM.dll спрашивает
программу о сценах.

Консоль (`~`) — вызвать из неё любую глобальную функцию:

```
cgf "OGAIAnim.Tags" "gesture,surrender" 14 "player"                 ; герой поднимает руки (14 - ссылка героя)
cgf "OGAIAnim.Tags" "gesture,talk,confident" <refid> "npc"           ; жест на NPC (refid - щёлкните NPC в консоли)
cgf "OGAIAnim.Tags" "gesture,talk,friendly" <refid> "npc" "head"     ; только голова
cgf "OGAIAnim.Tags" "hug,pair" <refid> "both"                        ; сцена героя и NPC с камерой
```

Журнал `Documents\My Games\Fallout4\F4SE\GAM.log`:

| Строка | Что значит |
|---|---|
| `play 3 'gesture/hands_up' (1 actors, part 1, first 00000014)` | запустилась сцена 3, часть тела 1 (верх) |
| `scene 3 'gesture/hands_up' ended after 3.4 s (frames: 00000014:205)` | закончилась; сколько кадров её получил каждый актёр (0 — актёр не обновлялся: выгружен или далеко) |
| `scene 1 asked to stop at 20.8 s` | скрипт попросил закончить (`Stop`, предел `WaitScene`) |
| `camera: following scene 1 (auto)` | камера взялась за сцену |
| `no scene 'x'` / `needs 2 actors, got 1` / `does not fit role` | id не найден / не хватает актёров / раса не подходит роли |
| `scene 3 'x' event sound 'Fallout4.esm\|0x0001A4E1' on 00000014` | событие сцены исполнено |
| `scene 3 'x' event say: no topic '…'` | событие не нашло формы (проверьте `Плагин\|0xID` и что плагин включён) |
| `scene 3 'x' face 'happy' on 0001A4D7` | дорожка лица сменила выражение |
| `G.A.M. editor: command 5 play 'editor/my/hug'` / `command 5 failed: …` | сцена из редактора («Проиграть в игре») и почему не сыграла |

В программе все журналы — ядра, игры, Papyrus и F4SE — собираются в одном файле `%APPDATA%\BoopiMod\logs\all.log`, а ошибки — в
`errors.log` рядом.

## 12. Частые ошибки

**Жест не виден в диалоге.**
Камера диалога держит крупный план лица. Верх тела виден плохо, кивок (`part: head`) — хорошо. Для рук берите `when: after` или
широкий жест.

**Сцена на двоих в диалоге «дерётся» с камерой диалога.**
Ставьте `when: after` или запускайте в `OnEnd` последней реплики.

**NPC стоит боком.**
В сцене на всё тело актёров ставят метки. Для жеста актёр остаётся, где стоит, — разверните его сами (`SetAngle`) или используйте
сцену.

**Сцена без этапов идёт 20 секунд.**
Это предел по умолчанию для зацикленной сцены. Задайте этапы ([5.1](#51-этапы-развитие-сцены)) или `afMaxSeconds`.

**Ничего не играет, в журнале пусто.**
Нет подходящей сцены. Проверьте `GAM.ListScenes("ваши,теги")` и поставьте пак с такими тегами.
