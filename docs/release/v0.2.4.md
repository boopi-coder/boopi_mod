## Русский

- **Переезд из Mod Organizer 2 и Vortex в пару кнопок.** Программа сама находит их моды для Fallout 4 и предлагает
  «Перенести». Моды приходят включёнными и выключенными как там, с теми же победителями в пересечениях файлов и тем же
  порядком плагинов. Файлы не копируются, MO2 и Vortex остаются рабочими. «Отменить перенос» возвращает всё как было,
  «Экспорт в MO2» — обратный путь (из MO2 моды забирает и Vortex).
- **Любой мод можно выключить переключателем.** Его файлы уходят из игры, возвращается то, что он перекрывал; включение
  ставит всё на место.
- **Установщики FOMOD.** Архив с установщиком открывает окно выбора с шагами, картинками и описаниями — как в других
  менеджерах.
- **Установка проверяет совместимость.** F4SE-плагин, сделанный под другую версию игры, плагин без нужных файлов-мастеров,
  архивы, которые игра не откроет — мод всё равно ставится, но вы видите, что не так. Проверка перед запуском называет
  такие плагины с кнопками «Выключить мод» и «Удалить мод».
- **Порядок загрузки умнее.** Учитывает, какие плагины правят одни и те же записи, лимиты на число плагинов и, если
  загрузить, список сообщества LOOT. Пересечения файлов между модами видны в списке модов.
- **MCM на юбилейной ставится только на 1.11.240** — его сборка работает лишь на этой версии; на других F4SE отключал его
  при каждом запуске. Если он уже стоит, в списке модов есть кнопка «Удалить».
- Если наши моды с boopi.site ещё не скачаны, моды базового пакета, собираемые из них, ждут с понятной подсказкой.
- После перезапуска программы на странице «Моды» не висят сообщения о давно завершённых установках.

Обновление ставится само: окно «Что нового» или «Настройки → О программе → Проверить сейчас».

## English

- **Move from Mod Organizer 2 and Vortex in a couple of clicks.** The app finds their Fallout 4 mods by itself and offers
  "Move". Mods come over enabled and disabled as they were, with the same winners where files overlap and the same plugin
  order. No files are copied; MO2 and Vortex keep working. "Undo the move" puts everything back, "Export to MO2" goes the
  other way (Vortex can take mods from MO2 too).
- **Any mod can be switched off.** Its files leave the game and whatever it covered comes back; switching it on puts
  everything back.
- **FOMOD installers.** An archive with an installer opens a choice window with steps, pictures and descriptions, as in
  other managers.
- **Installs check compatibility.** An F4SE plugin made for another game version, a plugin missing its masters, archives
  the game cannot open: the mod still installs, but you see what is wrong. The pre-launch check names such plugins with
  "Switch the mod off" and "Uninstall the mod" buttons.
- **A smarter load order.** It accounts for plugins that edit the same records, the plugin limits and, once downloaded,
  the LOOT community list. File overlaps between mods are shown in the mod list.
- **MCM on Anniversary installs only on 1.11.240**: its build runs on that version alone, and F4SE disabled it at every
  start on the others. If it is already installed, the mod list has a "Remove" button.
- When our mods from boopi.site are not downloaded yet, the base pack items built from them wait with a plain hint.
- After a restart the Mods page no longer shows notes about installs that finished long ago.

The update installs itself: the "What's new" window or Settings → About → Check now.
